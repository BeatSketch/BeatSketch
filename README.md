## Packaging notes
Due to lack of time, we currently only have three kinds of Linux packages.
- ArchLinux package (available in the [AUR](https://aur.archlinux.org/beatsketch))
- Semi-built tarball (which is what the PKGBUILD in the AUR uses to build)
- Fully built tarball (containing a self-contained executable)

There are plans to eventually also provide RPMs, Deb and AppImages, possibly also flatpaks.
We will *not* officially support snap packages
